# rxui-next

Unpublished research crate for RXUI's typed component and reconciled-view
authoring model.

It includes local typed actions and mapped action scopes, application effects,
keyed views, semantic tokens, real shaped labels and editable fields,
property-grid reconciliation, width-controlled visible-range tree/table views,
and a render-view slot.

```text
cargo run -p rxui-next --example editor_vertical_slice --offline
```

See [`docs/rfcs/ui-next.md`](../../docs/rfcs/ui-next.md).
The migration-facing contract is documented in [`API.md`](API.md).
